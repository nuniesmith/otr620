# Google Maps Platform - API & Pricing Reference

Source: [Google Maps Platform Pricing](https://mapsplatform.google.com/lp/maps-apis/#pricing) (Retrieved September 2026)

## Overview
Google Maps Platform offers flexible Maps API pricing with up to **$200 in free usage per month** (equivalent to free tiers across various product categories and APIs). Users can mix and match across three product categories and get started with up to 10K free calls per product.

---

## Service Tiers

### 1. Essentials
* **Description:** Integrate the most commonly used APIs into your applications.
* **Free Tier:** **10,000 free calls** per SKU per month.
  * *Note:* Essentials Map Tiles APIs provide up to **100,000 calls** at no cost per SKU per month.

### 2. Pro
* **Description:** Advanced features to build more differentiated experiences.
* **Free Tier:** **5,000 free calls** per SKU per month.

### 3. Enterprise
* **Description:** Maximum flexibility and control for large-scale operations.
* **Free Tier:** **1,000 free calls** per SKU per month.

## API Product Capabilities & Pricing ($0 Free Tiers)

The following APIs are available with $0 estimate per month for baseline hobbyist/personal use within free tiers:

### Dynamic Maps & Web Embeds
* **Dynamic Maps:** Customize and style interactive maps using Cloud-based maps styling for real-time updates across devices and platforms.
* **Embed API:** Add an interactive map or Street View panorama to your site using a simple HTTP request.
* **Mobile Native Dynamic Maps:** Cloud-styled interactive maps for mobile native platforms (iOS/Android).

### Static Maps & Panoramas
* **Static Maps:** Embed simple static map images on your website with minimal code.
* **Static Street View:** Embed a static (non-interactive) Street View panorama or thumbnail into your web page without using JavaScript.
* **Dynamic Street View:** Embed real-world imagery with 360° interactive panoramas.

### Map Tiles API
* **2D Map Tiles:** Design custom interfaces/visualizations unique to your brand and design requirements.
* **Street View Tiles:** Use images taken from street level and tile metadata to create immersive experiences.
* **Photorealistic 3D Tiles:** Access a 3D mesh model of the real world and use the renderer of your choice to create cinematic experiences.

### Elevation & Immersive Maps
* **Elevation API:** Query locations on the earth for elevation data via a simple interface.
* **Aerial View Videos:** Delight users with pre-rendered, 3D cinematic video of points of interest and their surroundings.
* **Immersive Maps:** Create immersive, real-world web experiences with interactive 3D maps, equipped with powerful rendering and visualization tools.

## Support Options
* **Standard Support (Free):** Recommended for non-business-critical workloads under development.
  * 24x5 response, excluding holidays.
  * Response via Google Cloud Console & email only.
* **Enhanced Support ($500/month + 3% of monthly charges):** Designed for production workloads with 24x7 response, incident reports, assistance with maps data quality, and technical support escalations.
